> **一指搞定全家三餐老少胃口！**  
> 專為台灣家庭主婦（從 30+ 輕熟女到 50+、60+ 銀髮美魔女）量身打造的當季三餐推薦與優雅料理輔助工具。

## 💡 專案核心定位重塑 (Positioning Pivot)

本專案擺脫過往單一「長輩適老化輔具」的狹隘框架，升級重塑為：  
**「全世代台灣家庭主婦的廚房靈感神隊友與優雅烹飪伴侶」**。

家庭主婦是家中餐桌的總指揮官。從剛步入婚姻、帶著幼兒的年輕媽咪，到孩子就學、節奏穩健的職場熟女，再到孩子離巢、重視體態養生與生活質感的**銀髮美魔女**——她們每天都在面對同一個靈魂拷問：  
**「今天三餐到底要煮什麼？」**

本 App 的使命是：**懂主婦的忙碌、體貼全家的胃口，用極簡無負擔的科技，讓從年輕人妻到銀髮美魔女都能優雅、從容地享受下廚樂趣！**

```
├─────────────────────────┼─────────────────────────┼─────────────────────────┤

│ • 偏好氣炸/電鍋一鍋出   │ • 帶便當菜需耐蒸不變色  │ • 要求操作極致簡單直覺  │
│ • 少油煙、維持好氣色    │ • 追求高效穩健出餐      │ • 追求優雅慢調、時令煲湯│
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### 1. 🌸 30+ 輕熟女（新手媽咪／職場人妻）
- **核心訴求**：高效省時、營養均衡、小孩愛吃、少油煙。
- **痛點**：工作家庭兩頭燒，下班備料像打仗；幼童挑食吃得慢，不知如何做開胃料理。
- **產品解法**：
  - 20~30 分鐘「快手出菜」推薦。
  - 氣炸鍋、電鍋與無油煙蒸煮料理標籤。
  - `#小孩超愛`、`#下飯神菜` 標籤直覺引導。

### 2. 🍳 40+ 熟女（全家餐桌樞紐／節奏掌控者）
- **核心訴求**：全家老少口味平衡、冰箱食材清倉、帶便當首選。
- **痛點**：天天想菜單想到枯竭；先生想吃重口味、小孩不吃青菜、長輩牙口不好，一桌菜難以面面俱到。
- **產品解法**：
  - 獨家 **「👨‍👩‍👧‍👦 全家共食撇步」**：一道菜「一鍋兩吃」（原味先盛給小孩長輩、剩下加蔥蒜辣椒起鍋給年輕人；豆腐吸高湯老少兼宜）。
  - 食材圖示勾選器：冰箱剩什麼點什麼，立即配對菜色。
  - 支援買菜清單一鍵轉傳 LINE（給先生買或自己備忘）。

### 3. 🍷 50+ / 60+ 銀髮美魔女（質感主婦／優雅掌廚女主人）
- **核心訴求**：字體超清晰且可調大、操作極度簡單直覺、低脂低鈉抗老煲湯、做菜優雅不狼狽。
- **痛點**：
  - **視力與字體**：近看手機食譜老花吃力，字體太小或太密容易疲勞，手機放在流理台遠處看不清。
  - **操作複雜度**：討厭複雜的子選單、深層切換或繁瑣輸入；廚房手微濕微油時難以精細觸控。
  - **健康體態**：不想被大火油煙燻臉，重視膠原蛋白與時令滋補。
- **產品解法**：
  - **字體清晰可調大 (Scalable Font)**：預設 1.5 倍大字排版（22px+），支援字級放大調整，高對比舒適不瞇眼，放中島流理台一眼即見。
  - **極致極簡操作 (Ultra-Simple Flow)**：零學習曲線，無複雜層級，超大直覺圖卡式按鈕，防油水誤觸，一指直達料理步驟。
  - **螢幕防黑屏 (Screen Wake Lock)**：料理途中螢幕常亮，雙手沾水沾粉時絕不黑屏。
  - **時令養顏煲湯**：搭配當季食材釋放天然鮮甜，少油少鹽低負擔。

## ✨ 核心特色與產品模組（11 大野心廚房神隊友）

### 1. 👨‍👩‍👧‍👦 動態「一鍋老少三段式時序解構引擎」
- **同一鍋・免煮三次**：
  - **階段 1【長輩與幼兒先行・軟爛清淡】**：食材燉至軟透、蔬菜剪小段，在下辣椒或重醬前盛起 1 碗無辣低鈉份量。
  - **階段 2【學童便當與發育・甜鹹下飯】**：放入雞蛋、豆腐裹上醬香甘甜紅汁，撈取便當菜與小朋友拌飯的最愛份量。
  - **階段 3【大人宵夜嗆香・大火收汁】**：轉大火下生辣椒、九層塔或沙茶，大火收濃汁嗆香起鍋！
- 完整納入**客家手路經典**（客家小炒、梅干扣肉、福菜肉片排骨湯、薑絲炒大腸）與**閩南傳統家常**（菜脯蛋、黑麻油老薑三杯雞、香菇瓜仔肉燥）。

### 2. 🍂 在地微氣候與 24 節氣時空感知推薦
- 動態計算台灣 24 節氣（如：霜降、立冬、小雪、冬至、小寒）。
- 首頁即時顯示微氣候潤燥、溫補指引與農糧署當令盛產（大菜、菜頭、老薑、五花肉），一鍵帶入。

### 3. 👩‍🍳 廚房「隱形隨侍」阿妹仔語音伴侶 ＋ 手油免碰大字計時器
- **雙手油油沾粉時全免摸**：開口說「下一步」、「上一步」、「重唸」，語音朗讀步驟。
- **免手觸控計時器**：開口「計時5分鐘」即刻啟動，倒數歸零時由 Web Audio API 播放清脆烤箱提示鈴聲，自動聯動防黑屏 (Screen Wake Lock)。

### 4. 🎙️ 多模態口述清冰箱 ＋ 台客雙聲道食材字典
- 冰箱裡塞滿紅白塑膠袋看不清？直接開口口述手邊食材：「我手邊有半條菜瓜、兩塊二層肉、一包大菜、半盒福菜」。
- 內建台語（菜瓜/刺瓜仔/菜頭/金瓜/二層肉/隔間肉）與客家語（大菜/覆菜/福菜/鹹菜乾/面帕粄/桔醬）同音字與俗名自動正規化，秒速精準配菜！

### 5. 👵 家族手路菜記憶典藏 (代代相傳家傳菜)
- 讓長輩或主婦用口述錄下阿嬤與媽媽的味道（「黑麻油煸老薑要煸到邊緣微捲、醬油黑白淋一圈」）。
- 智慧結構化永久儲存於手機私房資料庫，首頁金框置頂，還能一鍵轉傳 LINE 分享給兒女！

### 6. 🔄 一食材變三餐・食材鍊金術 (好市多／大包裝救星)
- 買了一大條帶皮五花肉或一整隻大土雞？
- 系統一鍵排出「買一次、連吃三天不同菜色」的連環菜單（如：五花肉 ➔ 第1天梅干扣肉 ➔ 第2天肉燥拌麵 ➔ 第3天客家小炒）！

### 7. ⚡ 30 分鐘三菜一湯平行開飯指揮官
- 勾選 2～3 道想煮的菜色，點擊一鍵啟動平行指揮官：
  - `00~06分`：一次性合流備料（蔥薑蒜一次切完，砧板只洗一次）。
  - `06~15分`：電鍋/煲湯先起火（免顧火）。
  - `15~24分`：左爐小火慢悶入味。
  - `24~29分`：右爐大火快炒時蔬。
  - `30分整`：三菜一湯熱騰騰同時上桌！

### 8. 📣 LINE 家庭群組點菜投票單 ＋ 採買小隊工單
- 一鍵產生「今晚菜單預告與家人點菜單」轉傳至家族 LINE 群組，附帶「下班順路幫買嫩豆腐」採買指派，讓家人晚餐更有期待感。

### 9. ❤️ 家人特別照顧模式 (4 大生活情境速選)
- 🎓 **考前衝刺補腦**（深海魚、卵磷脂豆腐、高蛋白提神）
- 🤧 **換季溫補養胃**（老薑黑麻油、清潤燉湯、去燥清肺）
- 🦷 **長輩幼兒極軟**（免咀嚼、吸飽湯汁冬粉、蒸豆腐、茄子煲）

### 10. 💡 菜市場阿婆級挑菜＆紅白塑膠袋保鮮微錦囊
- 解決台灣主婦「塑膠袋悶爛食材」的痛點，針對各食材提示挑菜訣竅與報紙/紙巾吸濕冷藏保鮮密技。

### 11. 👁️ 優雅抗疲勞介面設計 (Anti-Fatigue UX)

## 🛠️ 技術架構與資料模型

### 前端架構
- **純原生高效架構**：Vanilla HTML5 + Modern JavaScript (ES6+)。
- **樣式庫**：Tailwind CSS (CDN)，搭配優雅奶油大地色系 (`#FFFDF7`, `#FFF8EC`, `#9A3412`)。
- **語音識別**：Web Speech Recognition API，支援國台語食材輸入。
- **狀態持久化**：`localStorage`（儲存個人喜好、PIN 碼驗證、常點最愛食譜）。

### 資料庫規格 (`schema.sql`)
- **`seasonal_produce`**：台灣當季農產食材字典表（包含各食材盛產月份陣列）。
- **`cooking_methods`**：8 大烹調法字典表（圖示、用油度、特性描述）。
- **`recipes`**：料理食譜主表（全家餐桌標籤、共食撇步、精準 YouTube 起始秒數、步驟摘要）。
- **`recipe_ingredients`**：食譜食材規格表（支援買菜勾選與 LINE 轉傳格式）。
