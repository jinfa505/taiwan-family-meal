# 🍲 三餐煮什麼 — 台灣家庭主婦的每日靈感與美味神隊友

> **一指搞定全家三餐老少胃口！**  
> 專為台灣家庭主婦（從 30+ 輕熟女到 50+、60+ 銀髮美魔女）量身打造的當季三餐推薦與優雅料理輔助工具。

---

## 💡 專案核心定位重塑 (Positioning Pivot)

本專案擺脫過往單一「長輩適老化輔具」的狹隘框架，升級重塑為：  
**「全世代台灣家庭主婦的廚房靈感神隊友與優雅烹飪伴侶」**。

家庭主婦是家中餐桌的總指揮官。從剛步入婚姻、帶著幼兒的年輕媽咪，到孩子就學、節奏穩健的職場熟女，再到孩子離巢、重視體態養生與生活質感的**銀髮美魔女**——她們每天都在面對同一個靈魂拷問：  
**「今天三餐到底要煮什麼？」**

本 App 的使命是：**懂主婦的忙碌、體貼全家的胃口，用極簡無負擔的科技，讓從年輕人妻到銀髮美魔女都能優雅、從容地享受下廚樂趣！**

```

│  (職場媽咪 / 新手人妻)   │ (全家料理樞紐 / 節奏控)  │ (優雅熟齡 / 質感女主人)  │
├─────────────────────────┼─────────────────────────┼─────────────────────────┤

│ • 少油煙、維持好氣色    │ • 追求高效穩健出餐      │ • 追求優雅慢調、時令煲湯│
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### 1. 🌸 30+ 輕熟女（新手媽咪／職場人妻）
- **核心訴求**：高效省時、營養均衡、小孩愛吃、少油煙。
- **痛點**：工作家庭兩頭燒，下班備料像打仗；幼童挑食吃得慢，不知如何做開胃料理。
- **產品解法**：
  - 20~30 分鐘「快手出菜」推薦。
  - 氣炸鍋、電鍋與無油煙蒸煮料理標籤。
  - `#小孩超愛`、`#下飯神菜` 標籤直覺引導。

### 2. 🍳 40+ 熟女（全家餐桌樞紐／節奏掌控者）
- **核心訴求**：全家老少口味平衡、冰箱食材清倉、帶便當首選。
- **痛點**：天天想菜單想到枯竭；先生想吃重口味、小孩不吃青菜、長輩牙口不好，一桌菜難以面面俱到。
- **產品解法**：
  - 獨家 **「👨‍👩‍👧‍👦 全家共食撇步」**：一道菜「一鍋兩吃」（原味先盛給小孩長輩、剩下加蔥蒜辣椒起鍋給年輕人；豆腐吸高湯老少兼宜）。
  - 食材圖示勾選器：冰箱剩什麼點什麼，立即配對菜色。
  - 支援買菜清單一鍵轉傳 LINE（給先生買或自己備忘）。

### 3. 🍷 50+ / 60+ 銀髮美魔女（質感主婦／優雅掌廚女主人）
- **核心訴求**：字體超清晰且可調大、操作極度簡單直覺、低脂低鈉抗老煲湯、做菜優雅不狼狽。
- **痛點**：
  - **視力與字體**：近看手機食譜老花吃力，字體太小或太密容易疲勞，手機放在流理台遠處看不清。
  - **操作複雜度**：討厭複雜的子選單、深層切換或繁瑣輸入；廚房手微濕微油時難以精細觸控。
  - **健康體態**：不想被大火油煙燻臉，重視膠原蛋白與時令滋補。
- **產品解法**：
  - **字體清晰可調大 (Scalable Font)**：預設 1.5 倍大字排版（22px+），支援字級放大調整，高對比舒適不瞇眼，放中島流理台一眼即見。
  - **極致極簡操作 (Ultra-Simple Flow)**：零學習曲線，無複雜層級，超大直覺圖卡式按鈕，防油水誤觸，一指直達料理步驟。
  - **螢幕防黑屏 (Screen Wake Lock)**：料理途中螢幕常亮，雙手沾水沾粉時絕不黑屏。
  - **時令養顏煲湯**：搭配當季食材釋放天然鮮甜，少油少鹽低負擔。

## ✨ 核心特色與產品模組

### 1. 🌿 台灣當季時令蔬果對齊
- 深度整合農業部農糧署產季月份，即時推薦「正著時（盛產）」食材。
- 盛產食材營養最高、農藥最少、市場價格最划算，守護家庭預算與全家健康。

### 2. 🍲 獨創「👨‍👩‍👧‍👦 全家共食小撇步」
- 每道菜皆附主婦智慧傳承技巧：
  - *清蒸鮮魚*：盤底鋪滿嫩豆腐吸收魚汁，小孩舀滑豆腐、大人吃鮮魚。
  - *香滷控肉*：同鍋滷板豆腐與白煮蛋，大人配控肉、小孩挑滷蛋、長輩夾軟豆腐。
  - *洋蔥牛肉*：牛肉片醃薄芡滑熟，長輩小孩咬起來軟嫩如豆腐。

### 3. 🍳 8 大烹調法靈活切換
- 快炒、紅燒/滷製、清蒸/電鍋、燉煮/煲湯、香煎、烤箱/氣炸、川燙/涼拌、金黃油炸。
- 貼心配備 **「🚫 不吃油炸」** 一鍵過濾開關，為全家健康把關。

### 4. 👁️ 優雅抗疲勞介面設計 (Anti-Fatigue UX)
- **大字體與字級可調 (Scalable Font)**：預設放大 1.5 倍大字（22px+），並支援字級彈性放大調節，即使嚴重老花或手機放在遠處中島也能清晰看懂，不瞇眼不費力。
- **極致極簡操作 (Ultra-Simple Flow)**：完全去除多層深層選單，採用直覺單層卡片與超大按鈕；手濕微油時也能精準一指點選，防誤觸。
- **食材視覺化圖示**：每道菜具備超大食材按鈕，長按即刻顯示食材名稱與備料份量。
- **防止螢幕休眠**：開啟食譜詳細頁自動啟用 Wake Lock API，雙手忙碌無須觸碰喚醒。

### 5. 🔒 家庭 PIN 碼專屬保護 (Family PIN: 0854)
- 具備防誤觸與防閒雜人等進入的 PIN 碼機制（諧音「您發財」），勾選記住後全家人永久免密開啟。

### 6. 📱 PWA 跨平台體驗（免下載、免上架費）
- 支援 iOS Safari / Android Chrome 直接「加入主畫面」。
- 全螢幕沈浸體驗，無廣告、無干擾、無推播轟炸。
- 內建離線快取 Service Worker，廚房收訊不佳照樣順暢看食譜。

## 🛠️ 技術架構與資料模型

### 前端架構
- **純原生高效架構**：Vanilla HTML5 + Modern JavaScript (ES6+)。
- **樣式庫**：Tailwind CSS (CDN)，搭配優雅奶油大地色系 (`#FFFDF7`, `#FFF8EC`, `#9A3412`)。
- **語音識別**：Web Speech Recognition API，支援國台語食材輸入。
- **狀態持久化**：`localStorage`（儲存個人喜好、PIN 碼驗證、常點最愛食譜）。

### 資料庫規格 (`schema.sql`)
- **`seasonal_produce`**：台灣當季農產食材字典表（包含各食材盛產月份陣列）。
- **`cooking_methods`**：8 大烹調法字典表（圖示、用油度、特性描述）。
- **`recipes`**：料理食譜主表（全家餐桌標籤、共食撇步、精準 YouTube 起始秒數、步驟摘要）。
- **`recipe_ingredients`**：食譜食材規格表（支援買菜勾選與 LINE 轉傳格式）。
